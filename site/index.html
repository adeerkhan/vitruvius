Engineering research agent

Evidence first. Naming second.

Vitruvius runs a research loop over engineering questions and artifacts — discover, read, synthesize, verify, review — and records where every claim came from.

A search engine returns snippets

Vitruvius opens the source, records the provision, and hands you a claim you can walk back to a page number.

01

Reads, never infers

A code provision, a spec value, a material property is read before it is summarised — not inferred from a title, a snippet or memory.

02

Never fabricates

Every named standard, product, project or dataset carries a verifiable reference. If none was found, it is not mentioned.

03

Records provenance

Outputs ship a .provenance.md sidecar naming what was checked and how, so a reader can audit rather than trust.

The research loop

Seven phases, every time

The last phase is a gate: the run is not done until an independent check re-derives the question and finds it answered.

  1. I

    Plan

    Questions, evidence, scale decision.

  2. II

    Scale

    Direct search, or decompose across agents.

  3. III

    Gather

    Open sources, record exact provisions.

  4. IV

    Draft

    Synthesise with citations as you write.

  5. V

    Cite

    Sweep every claim back to its source.

  6. VI

    Review

    Blind check, eight adversarial tests.

  7. VII

    Deliver

    Goal-check gate. Output plus provenance.

Install

One command, then restart the harness

The skill catalogue is built at startup, so a newly installed skill is not routable until the next session.

npx skills add adeerkhan/vitruvius

Every harness is supported. The installer renders the adapters a project needs, or, with --global, drops the skills bundle into a harness's own config root.

Claude Code
npx skills add adeerkhan/vitruvius
Cursor
npx @adeerkhan/vitruvius --host cursor
Codex
npx skills add adeerkhan/vitruvius --agent codex
OpenCode
npx @adeerkhan/vitruvius --host opencode
Kilo · VS Code · Prime · OMP · DeepSeek · Hermes · Grok · Reasonix
npx @adeerkhan/vitruvius --global --all
Pi
pi install git:github.com/adeerkhan/vitruvius
