# Fixture: Design Alternatives Test Input

## Problem Statement
Select a joining method for connecting additively manufactured Ti-6Al-4V brackets to wrought Ti-6Al-4V spars in a commercial aircraft secondary structure.

## Constraints

### Hard
- Fatigue life: >100,000 cycles at 80% of yield strength
- Operating temperature: -54°C to +85°C
- Must be inspectable by NDE (ultrasonic or X-ray)
- Compliance with FAA AC 25.571-1D damage tolerance

### Soft
- Minimize weight penalty
- Minimize recurring cost
- Maximize repairability
- Prefer established aerospace supply chain

## Expected Output Shape
- 3-5 alternatives (e.g., LFW, FSW, LBW, mechanical fastening, adhesive bonding)
- Each with: Approach, Governing standards, Advantages, Limitations
- Comparison matrix with weighted criteria (fatigue, weight, inspectability, cost)
- Recommendation with trade-offs (not a single answer)
