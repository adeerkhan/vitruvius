---
description: Compare standards, designs, products, or methods into a source-grounded matrix of agreements and confidence. Usage: /compare <items to compare>
---

Run the engineering source comparison workflow on the $ARGUMENTS items:
activate `/skill:compare`. Build a matrix (source, key claims, evidence type,
caveats, confidence), read each source directly with standard + section +
edition, distinguish agreement/disagreement/uncertainty, and save to
`outputs/<slug>-comparison.md` with a Sources section.
