Run the standards lookup skill on the $ARGUMENTS query: activate
`/skill:standards-lookup`. Select the authoritative standard for the domain
and jurisdiction, locate the governing section, and return the provision with
provenance. Distinguish mandatory ("shall") from advisory ("should"). Flag
paywalled access and cite by standard + section + edition. When two
applicable standards conflict, report both and identify which the project
specification designates as governing.
