# AISC 358 — Prequalified Connections for Special and Intermediate Steel Moment Frames

## Scope

Prequalified connection designs for steel moment frames (SMF and IMF).
Provides tested connection details that satisfy AISC 341 seismic
requirements without project-specific testing. Using a prequalified
connection from AISC 358 streamlines design and plan review. The standard
covers reduced beam section (RBS), bolted unstiffened and stiffened extended
end-plate, bolted flange plate (BFP), welded unreinforced flange – welded
web (WUF-W), and newer connections.

## Prequalified connections (AISC 358-16 / -22)

| Connection | Type | Key feature |
|---|---|---|
| Reduced Beam Section (RBS) | Welded | Beam flanges reduced away from column face; plastic hinge relocates |
| Bolted Unstiffened Extended End-Plate (BUEEP) | Bolted | Extended end-plate bolted to column; shop-welded to beam |
| Bolted Stiffened Extended End-Plate (BSEEP) | Bolted | Stiffened extended end-plate; shop-welded to beam |
| Bolted Flange Plate (BFP) | Bolted | Flange plates bolted to column and beam |
| Welded Unreinforced Flange – Welded Web (WUF-W) | Welded | Full-penetration groove welds at flanges, shear tab at web |
| Kaiser Bolted Bracket (KBB) | Bolted | Proprietary bracket; license required |
| ConXtech CONXL moment frame | Bolted | Proprietary; license required |
| Simpson Strong-Bolt 2 (SSB) | Bolted | Proprietary; license required |

## Relationship to AISC 360 and 341

- **AISC 341** requires moment frame connections to meet cyclic performance
  criteria.
- **AISC 358** provides connection details that are *pre-qualified* to meet
  AISC 341 criteria without additional cyclic testing.
- The engineer selects a connection from AISC 358 and applies the limits
  (beam depth, column depth, material grade, protected zone).

## When to use

Use this reference when:
- Designing SMF or IMF connections.
- Selecting a prequalified moment frame connection.
- Checking beam/column limits for a prequalified connection.
- Referencing protected zone requirements.
