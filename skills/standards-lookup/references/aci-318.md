# ACI 318 — Building Code Requirements for Structural Concrete

## Scope

The central US code for structural concrete design (cast-in-place and
precast). Covers beams, columns, slabs, walls, footings, and connections.
Mandatory language ("shall") is the enforceable code; commentary is
explanatory only.

## Edition history

| Edition | Year | Notable changes |
|---|---|---|
| ACI 318-08 | 2008 | Previous widely-adopted edition |
| ACI 318-14 | 2014 | Major rewrite: new seismic chapter, revised development length |
| ACI 318-19 | 2019 | Current widely-adopted; major shear provisions rewrite, new headed bar provisions |
| ACI 318-25 | 2025 | Latest; updated seismic, sustainability provisions |

Shear provisions changed significantly between -14 and -19. Always confirm
the edition.

## Mandatory-language conventions

- **"shall"** — mandatory (the code requirement)
- **"shall not"** — mandatory prohibition
- **"should"** — recommended (advisory)
- **"may"** — permitted (optional)
- **Commentary (R sections)** — explanatory; cite as "ACI 318-19, R9.3.2"

## Known conflicts and cross-checks

| Conflicts with | Issue |
|---|---|
| ACI 350 | Environmental structures (tanks, clarifiers) use ACI 350, which modifies 318 for crack control and exposure. |
| ACI 349 | Nuclear structures; different load factors and ductility requirements. |
| Eurocode 2 (EN 1992) | Different material partial factors, different shear model. Not interchangeable. |
| ASCE 7 | ACI 318 references ASCE 7 for load combinations. Match editions. |

## Jurisdiction notes

- **US (general):** ACI 318 is referenced by the IBC for concrete structures.
  IBC 2021 references ACI 318-19; IBC 2024 references ACI 318-25.
- **Seismic regions:** ACI 318 Chapter 18 governs; special detailing required
  for high seismic design categories (SDC D/E/F).
- **Parking structures:** Exposure class for de-icing chemicals requires tighter
  crack control (§24.3) and potentially lower w/c ratio (§19.3.2.1).
- **Canada:** CSA A23.3 governs, not ACI.
