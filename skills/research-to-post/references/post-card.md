# Post Card and Media

The card is the delivery surface: 2–3 hook posts at the top, a Copy button on
each, a Copy all posts button, the source links, the source's own media, and the
claim ledger in a collapsed section. It is generated by
`scripts/render-post-card.mjs`; do not hand-write the HTML.

The card is a preview, not a publication step. Nothing here posts, schedules, or
scrapes X.

## Posts

- `single`: 1 post.
- `thread`: 2 or 3 posts. Never 4 or more.
- `figure`: 1 post built around the source's figure.

Every post is a hook. A hook opens a gap; it does not close it. If a post
explains the whole result, cut it. The link in the last post carries the rest.

The renderer enforces: 2–3 posts for a thread, no link in the first post, the
source URL in the last post, and the character limit.

## Media items

`media.items` is an array of 1–6 items. Each item has:

| Field | Required | Meaning |
|-------|----------|---------|
| `kind` | yes | `image`, `gif`, `video`, `chart`, or `text` |
| `src` | image/gif/video | local `outputs/<slug>-media-<n>.png` (or `.mp4`/`.webm`) or an http(s) URL |
| `poster` | no | video poster; local image or http(s) URL |
| `alt` | yes | what the visual shows, including the number and baseline |
| `caption` | no | figure/table/screenshot label |
| `credit` | yes | author, figure number, repo, or project page |
| `license` | image/gif/video | the actual license, e.g. `CC BY 4.0`, `Apache 2.0` |
| `licenseChecked` | image/gif/video | `true` only after the license was read |
| `sourceUrl` | no | the page a reader can open |
| `chart` | chart | `{ type, title, unit, data }` |
| `text` | text | the one-line text card |

Local media must live under `outputs/`. Images are embedded as data URIs; videos
are linked by a relative path. Remote media is linked directly, so the card
opens the original.

### PDF figure

```json
{
  "kind": "image",
  "src": "outputs/softmax-precision-cliff-figure.png",
  "alt": "Figure 3: normalized Adam step versus logit margin. The step collapses at the fp32 cliff c32, and the equilibrium log(1/epsilon) sits just above it.",
  "caption": "Normalized Adam step vs. logit margin at epsilon = 1e-8.",
  "credit": "Figure 3, Barron, Gnanapragasam & Tschannen, arXiv:2610.31642v1",
  "license": "CC BY 4.0",
  "licenseChecked": true,
  "sourceUrl": "https://arxiv.org/abs/2610.31642"
}
```

### GitHub or project-page screenshot

```json
{
  "kind": "image",
  "src": "outputs/elephant-goldfish-hooks-media.png",
  "alt": "Screenshot of the Elephant-Goldfish Model project page: 'Design with an elephant. Review with a goldfish.'",
  "caption": "The project page's hero screenshot.",
  "credit": "Screenshot from egm.dev, Apache 2.0.",
  "license": "Apache 2.0",
  "licenseChecked": true,
  "sourceUrl": "https://egm.dev"
}
```

### Video or GIF

```json
{
  "kind": "video",
  "src": "outputs/<slug>-media-1.mp4",
  "poster": "outputs/<slug>-media-1-poster.png",
  "alt": "Demo: a design doc is reviewed by a fresh Goldfish subagent.",
  "caption": "The review demo from the project page.",
  "credit": "Demo from the project page, Apache 2.0.",
  "license": "Apache 2.0",
  "licenseChecked": true,
  "sourceUrl": "https://egm.dev"
}
```

Use `kind: "gif"` for an animated GIF; it renders as an image.

### Chart fallback

Use a chart only when the source has no usable visual. Every point must name a
`verified` or `partial` ledger claim and match its value (or its `baseline` when
`role` is `baseline`).

```json
{
  "kind": "chart",
  "alt": "Bar chart: fp32 cliff at 16.6 and AdamW equilibrium at 18.4.",
  "credit": "Chart built from Figure 1 and Eq. 11 of arXiv:2610.31642v1.",
  "chart": {
    "type": "bar",
    "title": "fp32 softmax cliff vs AdamW equilibrium",
    "unit": "logit margin",
    "data": [
      { "label": "fp32 precision cliff", "value": 16.6, "claim": "C1" },
      { "label": "AdamW equilibrium (ε=1e-8)", "value": 18.4, "claim": "C2" }
    ]
  }
}
```

### Text card

```json
{
  "kind": "text",
  "text": "The result holds for the tested frame only.",
  "alt": "Text card: the result holds for the tested frame only.",
  "credit": "Text card built from Section 4.2."
}
```

## Card input JSON

Save the input to `outputs/.drafts/<slug>-post-card.json`.

```json
{
  "slug": "softmax-precision-cliff",
  "title": "The softmax precision cliff",
  "source": {
    "citation": "Barron et al., arXiv:2610.31642v1",
    "url": "https://arxiv.org/abs/2610.31642",
    "projectUrl": "https://example.org/project",
    "repoUrl": "https://github.com/owner/repo"
  },
  "format": "thread",
  "limit": 280,
  "angle": "Counterintuitive finding",
  "angle_reason": "The usual max-subtraction fix is expected to make softmax safe; the paper finds two remaining bugs.",
  "hooks": [
    { "text": "Hook A ...", "recommended": true },
    { "text": "Hook B ...", "recommended": false },
    { "text": "Hook C ...", "recommended": false }
  ],
  "post": [
    { "text": "Hook 1 ...", "claims": ["C1"] },
    { "text": "Hook 2 ...", "claims": ["C2"] },
    { "text": "Hook 3 ... https://arxiv.org/abs/2610.31642", "claims": ["C3"] }
  ],
  "claims": [
    {
      "id": "C1",
      "claim": "fp32 precision cliff",
      "value": "16.6",
      "unit": "logit margin",
      "baseline": "bf16 5.5; fp64 36.7",
      "source_location": "Figure 1 caption; Section 2",
      "status": "verified",
      "used": true
    }
  ],
  "media": {
    "why": "Figure 3 is the paper's own visual for the cliff/equilibrium gap.",
    "items": [ { "kind": "image", "...": "..." } ]
  },
  "verification": {
    "verified": 1,
    "partial": 0,
    "blocked": 0,
    "checked_by": "verifier subagent (blind) — PASS",
    "notes": "Figure 3 and Table 1 checked against the PDF."
  }
}
```

## What the script refuses

The render exits non-zero, names the problem, and writes no card when:

- a `thread` has 1 or 4+ posts;
- a post exceeds the character limit;
- the first post contains a link;
- the last post does not contain `source.url`;
- a `used` claim is not `verified` or `partial`, or a `partial` claim has no
  `qualifier`;
- a post references a missing claim, or a `used` claim is never referenced;
- an image/gif/video is missing `alt`, `credit`, `license`, or
  `licenseChecked: true`;
- a local media path is outside `outputs/` or does not exist;
- a chart point names a missing claim, a claim that is not `used`, or a value
  that does not match the ledger;
- the `verification` counts disagree with the ledger;
- `slug` is not lowercase-hyphen-separated.

## CLI

```bash
node skills/research-to-post/scripts/render-post-card.mjs --input <json> --output <html>
node skills/research-to-post/scripts/render-post-card.mjs --input <json> --check
```

`--check` validates only. The HTML is self-contained for local images; remote
media is linked. The only behaviours are Copy, Copy all posts, and the chart's
PNG download.
