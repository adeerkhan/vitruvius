# Evidence Quality Tiers

Score all evidence using this tier system. Every critical claim must trace to
Tier 1 (authoritative) or Tier 2 (reliable) sources. Tier 3 supports but does
not standalone critical claims. Tier 4 is rejected as primary evidence.

| Tier | Description | Examples |
|------|-------------|----------|
| **Tier 1** | Authoritative | Official standards, code body text, primary vendor documentation, peer-reviewed engineering literature |
| **Tier 2** | Reliable | Reputable government/industry sources, established trade publications with cited primary backing |
| **Tier 3** | Supporting | Well-cited secondary sources, established trade publications without primary backing |
| **Tier 4** | Rejected | Undated blog posts, content aggregators, forum posts, SEO listicles, AI-generated content with no primary backing |

## Rules

- Every critical claim must trace to Tier 1 or Tier 2.
- Tier 3 may support but never standalone a critical claim.
- Tier 4 is never primary evidence.
- Mark each claim's verification status honestly: `verified`, `partial`, `blocked`, `unverified`, `inferred`, or `failed`.
